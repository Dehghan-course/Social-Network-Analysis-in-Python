# تحلیل شبکه‌های اجتماعی با پایتون

## معرفی

این مخزن شامل دیتاست‌ها، فایل‌های تمرین، پروژه‌ها و سایر فایل‌های موردنیاز دوره **تحلیل شبکه‌های اجتماعی با پایتون** است.

در این دوره علاوه بر آشنایی با مفاهیم نظری تحلیل شبکه، نحوه پیاده‌سازی الگوریتم‌ها و تحلیل شبکه‌های واقعی با استفاده از زبان Python و کتابخانه **NetworkX** آموزش داده می‌شود.

---

## سرفصل‌های دوره

- مفاهیم پایه گراف و شبکه
- نمایش و ذخیره‌سازی گراف‌ها
- کتابخانه NetworkX
- معیارهای ساختاری شبکه
- معیارهای مرکزیت (Centrality Measures)
- PageRank و HITS
- Community Detection
- مدل‌های گراف تصادفی
- Link Prediction
- تحلیل و مصورسازی شبکه‌ها
- پروژه‌های عملی و تحلیل شبکه‌های واقعی
