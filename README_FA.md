# تحلیل شبکه‌های اجتماعی با پایتون

🇬🇧 نسخه انگلیسی این فایل در [README.md](README.md) در دسترس است.

## 📖 معرفی

این مخزن شامل **دیتاست‌های مورد استفاده** در دوره [**تحلیل شبکه‌های اجتماعی با پایتون**](https://maktabkhooneh.org/course/%D8%AA%D8%AD%D9%84%DB%8C%D9%84-%D8%B4%D8%A8%DA%A9%D9%87-%D8%A7%D8%AC%D8%AA%D9%85%D8%A7%D8%B9%DB%8C-%D8%A8%D8%A7-%D9%BE%D8%A7%DB%8C%D8%AA%D9%88%D9%86-mk15965/) است.

در این دوره، علاوه بر آشنایی با مفاهیم نظری تحلیل شبکه، نحوه پیاده‌سازی الگوریتم‌ها و تحلیل شبکه‌های واقعی با استفاده از زبان **Python** و کتابخانه **NetworkX** آموزش داده می‌شود.

### سرفصل‌های دوره

- مفاهیم پایه گراف و شبکه
- نمایش و ذخیره‌سازی گراف‌ها
- کتابخانه NetworkX
- معیارهای ساختاری شبکه
- معیارهای مرکزیت (Centrality Measures)
- PageRank و HITS
- Community Detection
- مدل‌های گراف تصادفی
- Link Prediction
- تحلیل و مصورسازی شبکه‌ها
- پروژه‌های عملی و تحلیل شبکه‌های واقعی
