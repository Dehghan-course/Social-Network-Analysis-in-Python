## 📖 About the Course

This repository contains the datasets, for source code and additional materials used throughout the [**Social Network Analysis in Python**](https://maktabkhooneh.org/course/%D8%AA%D8%AD%D9%84%DB%8C%D9%84-%D8%B4%D8%A8%DA%A9%D9%87-%D8%A7%D8%AC%D8%AA%D9%85%D8%A7%D8%B9%DB%8C-%D8%A8%D8%A7-%D9%BE%D8%A7%DB%8C%D8%AA%D9%88%D9%86-mk15965/) course visit the [Maktabkhooneh](https://maktabkhooneh.org/).

The course covers both the theoretical foundations and practical implementation of social network analysis using Python.

### Topics Covered

- Graph fundamentals
- Network representation
- NetworkX library
- Centrality measures
- Community detection
- Random graph models
- Link prediction
- Network visualization
- Real-world case studies
